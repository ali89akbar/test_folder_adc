🔍 Discovered Application Defects & Resolutions
BUG-UI-001 (Resolved) Login State Mutation Overwrites Form Validation Message
Fixed in Login.jsx

Symptoms: When user attempts to submit the login form with empty username or password, the UI failed to display the validation warning ("Please enter your username and password.").

Root Cause: In src/components/layout/Login.jsx:80, the updater function was defined as: const update = (key, value) => setForm(f => ({ ...f, [key]: value, err: "" }));. When calling update("err", "Please enter your username and password."), the trailing err: "" property overwritten the [key]: value assignment, resetting the error message to an empty string.

- const update = (key, value) => setForm(f => ({ ...f, [key]: value, err: "" }));
+ const update = (key, value) => setForm(f => ({ ...f, err: "", [key]: value }));
🛡️ Security Verification Matrix
VERIFIED 403
CORS Strict Origin Allowlist

Unauthorized origins (e.g. evil-attacker.com) are rejected immediately with 403 Forbidden. Whitelisted origins (localhost, 10.224.118.151) succeed.

VERIFIED 401
Single Active Session Enforcement

Concurrent logins invalidate previous user sessions. Stale session IDs are rejected with 401 Unauthorized.

VERIFIED 429
Brute-Force Rate Limiting

Login endpoint (/api/auth/login) strictly rate limits failed login attempts to 5 per 15-minute window, issuing 429 Too Many Requests.

VERIFIED 413
Payload Size Limitation

Requests exceeding the 100kb threshold are terminated immediately with 413 Payload Too Large, mitigating buffer exhaustion attacks.

VERIFIED 500
Information Disclosure Prevention

Unexpected MySQL errors are caught and masked with a generic internal server error without leaking stack traces or internal OS filesystem paths.

VERIFIED 400
Strict Input Sanitization

Passwords must strictly conform to 8-72 characters. Sites must be KHI or LHE. Role values are constrained to admin or user.
